About StudentHub

A semester project for Web Development Frameworks (ITUE203) at CHARUSAT.

User roles

  • Visitor – view public pages, register, contact.
  • Student – dashboard, profile, event registration.
  • Admin – manage students, events and the audit log.

Tech stack

HTML5, CSS3 (Grid & Flexbox), JavaScript ES6, PHP, MySQL, Fetch API, XAMPP.
