# Static HTML pages (Practicals 2, 3, 4, 5, 6)
Plain `.html` pages sharing `../assets/css/style.css` and `../assets/js/*.js`. No PHP/MySQL needed.
Open via XAMPP (`http://localhost/studenthub/static/index.html`) or VS Code Live Server — the Events page uses Fetch, which does not work from `file://`.
Login/Contact/Feedback/Profile are demo-only here; the real versions are the `.php` pages in the parent folder.
